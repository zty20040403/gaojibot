# 高级 App 预览版：第一次怎么用

这是把机器人安装到**这台电脑或你自己的服务器**上的客户端，不会连接开发者的机器人。当前为 0.1.33 预览版，不是已全部验收的正式 V1；QQ 全流程、Windows 完整验收和完整服务器维护流程仍待验收。

从 [官方安装包页面](https://github.com/zty20040403/gaoji-app/releases/tag/app-v0.1.33) 下载。不要把 GitHub 自动提供的 `Source code` 当作安装包。0.1.28 及之前的更新器存在 GitHub 跳转兼容问题，若显示网络错误，请手动安装本版一次；之后可在 App 右上角检查更新，已有连接配置保留。

右上角“主题”打开主题工坊。点森林、海盐、花信或石墨的预览即可切换整套配色和涂鸦按钮，下面选择浅色、深色或跟随系统。设置立即保存，“完成”关闭面板。

## 机器人不回复时

1. 在已安装的实例中，点“运行检查”。QQ 已登录和 QQ 已接入机器人是两项独立结果。
2. 看“需处理”的项目，点右侧箭头进入对应设置。主动停止的机器人显示“未启用”，不会被误报为故障。
3. 模型配置不等于模型可用。点“测试默认模型”并确认后，才会发一次可能计费的实际请求；使用已经保存的设置，不使用未保存草稿。
4. 修改配置后重新检查。结果一分钟后过期；打开本页不会自动修复、重启或发群消息。
5. 需要求助时，点右上角下载图标导出匿名报告。报告不含 Key、登录信息和聊天。

旧实例缺少连接心跳时会显示“未确认”，不能把它理解为已经掉线。服务器和本机实例均可单独升级运行包，不要为了获得心跳检查而删除数据重装。

## 不买服务器，直接在这台电脑上用

1. 打开 App，点左侧“这台电脑”。
2. 没有 Docker Desktop 就点“下载 Docker Desktop”，按官方安装器完成安装并打开。Windows 需要 WSL2，按系统提示启用或重启；不用安装 Python、数据库或 Linux 服务器。
3. 回 App 点右上角重新检测。就绪后点“安装到这台电脑”，等待数据库和 QQ 组件安装完成；第一次下载可能较久。
4. 手机 QQ 扫码，填写自己的 API 地址、模型、Key、管理员 QQ 和群号，保存并启用。
5. 点“打开控制台”。机器人数据留在这台电脑的专属 Docker 数据卷，与服务器上的高级无关。

建议电脑至少 8 GB 内存，Docker 至少分配 4 GB，首次留出 15 GB 可用空间。关机、睡眠或关闭 Docker 时机器人会离线；要全天在线仍适合使用服务器。

本机版已提供可选高级沙盒和运行包升级。安装新版 App 不会自动升级旧本机实例。安装失败点继续，不要删除 Docker 数据重来；Docker 重置会丢失本机机器人数据。

### 更新本机机器人

1. 安装新版 App，点“这台电脑 → 更新与回退”。
2. 核对“本机机器人版本”和“此 App 携带的版本”，点“更新此实例”。不要在 Agent 仍有任务时更新。
3. 更新先准备并校验镜像，再备份、验证数据库和切换。准备下载阶段关闭 App 后需要点继续；交给独立后台后，关闭 App 不会取消任务。
4. 断线或失败时重新打开同一实例，点“继续原版本任务”。原任务编号不变，不新增数据库。
5. 更新完成后点“运行检查”，再到自己的测试群确认回复。需要回退时选择升级前回退点；回退不是把新旧聊天自动合并。

### 开启本机文件和代码沙盒

在“QQ 与模型 → 功能组件”打开“隔离沙盒”，保存并应用。首次需要 Docker 引擎至少 6 GiB 内存、12 GiB 可用空间；工具镜像目前为 x86_64，在 Apple Silicon 上使用模拟执行，首次编译可能较久。工具镜像不随每次普通 Bot 更新重建。

试用时让机器人“在沙盒里生成一个只有中文标题的 PDF，发到这个测试群”。文件生成、从沙盒取出、QQ 实际收件是三个步骤；必须在手机收到并打开才算完整成功。存储页会显示工作卷和工具缓存占用。基础聊天可以不启用沙盒。

自 0.1.28 起可以继续连接旧本机实例，原管理容器停止时也能启动它，不必为此保留旧版 App。原数据卷或管理容器缺失时会报错并保留现有数据，不会自动新建一个空实例冒充恢复。

## 准备什么

- 一台可通过 SSH 登录的 x86_64 Linux 服务器。安装器面向 Debian 12/13、Ubuntu 22.04/24.04 和 NixOS；不是给空硬盘装操作系统。
- 服务器地址、登录账户，以及密码或私钥。账户需要管理员权限；共享服务器先得到管理员同意。
- 自己的机器人 QQ、手机 QQ，以及模型服务提供的 API 地址、模型名称和 Key。
- 至少 10 GiB 可用磁盘；启用沙盒前还会检查至少 6 GiB 引擎内存、12 GiB 可用空间。服务器需要能下载依赖。

不用提前安装 Python、PostgreSQL 或 Docker，不用手写配置文件。App 会先检查并展示改动，点安装后才执行。它不会帮你配置路由器或绕过 SSH 登录。

## 在电脑打开

- Apple Silicon Mac：打开 `Gaoji-0.1.33-arm64.dmg`，将 Gaoji 拖到 Applications，再打开。这个包不是 Intel Mac 版。
- Windows x64：运行 `Gaoji-Setup-0.1.33.exe`；不想安装可解压 `Gaoji-0.1.33-win.zip` 后运行 `Gaoji.exe`。
- 两端暂未签名，Windows 尚未完成全部验收。遇到系统安全提示先核对文件来源和发布页上的 `SHA256SUMS`，不要全局关闭系统安全保护。

## 依次点这几步

1. **连接第一台服务器**：填自己的地址和账户，选择密码或私钥。首次连接核对显示的服务器指纹；不确定就问管理员，不要盲点。
2. **查看安装清单**：确认软件、目录、服务和磁盘要求。再点“安装到此服务器”，需要时输入服务器 sudo 密码。
3. **等待安装**：首次下载组件可能较久。关闭 App 不会取消后台安装；重开后选同一连接查询，不要另建连接重复安装。
4. **登录 QQ**：安装就绪后，在 App 显示的二维码上扫码并在手机确认。二维码过期就刷新，不要把二维码或登录令牌发给别人。
5. **配置模型**：填写自己的地址、模型和 Key，点“测试连接”。自建无密钥服务可以选择不需要 Key。测试会发出一次真实请求，可能计费。
6. **选择群**：填自己的管理员 QQ 和希望启用的群号。群号留空默认不回复任何群；测试时建议只填一个自己的测试群。
7. **启用机器人**：保存配置，设置控制台账户密码，再启用。不要同时在两台服务器登录同一个机器人 QQ。
8. **试一下**：在测试群 @ 机器人问一句话。再按需要开启识图、语音、子 Agent、沙盒等组件，逐项试用。

## 第一次服务器试用的验收顺序

只在你获准部署的测试服务器上操作，不要同时登录已经在其他服务器运行的机器人 QQ。

1. 安装前记下 App 显示的可用空间和安装清单，确认地址、账户与目标机器。不要因为地址来自旧连接就跳过身份核对。
2. 安装中记录任务编号。关闭并重新打开 App，选择原连接；应回到同一个任务，不应新增第二个实例。首次构建需要下载依赖，耗时取决于服务器网络；当前发行包未附带可直接拉取的预构建运行镜像。
3. 安装完成后分别核对数据库健康、QQ 已登录和模型连接测试。看到二维码、systemd 运行或模型名称列表，都不能单独证明机器人已经能回复。
4. 先只启用一个自己的测试群，发送 `@机器人 你好`，收到回答后再发普通消息并追问 `@机器人 你觉得呢`，检查它是否接上刚才的话题。
5. 需要文件功能时，启用并完成沙盒安装，再请求“生成一个只有中文标题的 PDF，发到这个群”。在手机 QQ 实际收到并打开文件，才算交付成功；控制台显示生成完成不算。
6. 关闭 App，确认服务器中的机器人仍可回复。此步骤不要求重启共享服务器；没有维护许可时不要拿整机重启作测试。
7. 记录失败的阶段、任务编号和脱敏报错。沿原任务查询或继续，不用删数据库、重装系统或新建连接来重试。

以上是待你实际执行的步骤，不是已经在你的服务器通过的测试记录。卸载只移除本实例资源；没有必要为了验收去删除重要数据。试用后停止、备份及删除的区别见本文末尾。

“打开控制台”会由 App 建立本地转发。关闭 App 后转发会断开，但服务器中的机器人仍运行。依赖其他平台或服务的功能，需要填写你自己的接口和凭据。

只想先试聊天，不需要开启外部集群。有自己的 Gaoji Cluster Control 网关时，再在“功能组件 → 外部集群”填地址和 Token，检测后保存并应用。群权限留空默认只允许管理员；这不会自动给你的服务器授予管理权限。详细步骤见 [外部集群说明](README.md#外部集群)。

需要把 QQ 群消息转到自己的 Matrix 房间时，再开“Matrix 消息互通”。填写自己账户的服务地址、用户 ID、Token 和群/房间对应关系，检测后保存并应用。开启后两边会互转消息，应先征得群成员同意；不支持加密房间。只用 QQ 无需配置。详见 [互通步骤](README.md#matrix-消息互通)。

自己另有运行 BlueBubbles 的 Mac，才需要“iMessage 消息互通”。填写该服务地址、API 密码、自身标识和指定会话，检测后保存并应用；不会把 iMessage 安装到 Linux。只读检测不等于发送验证，请用自己的测试会话核对实际文本互通。详见 [iMessage 步骤与限制](README.md#imessage-消息互通)。

## 出错时怎么做

| 看到什么 | 怎么处理 |
| --- | --- |
| 无法连接服务器 | 核对地址、SSH 端口和账户；地址仅在内网可达时，先接入对应网络 |
| 指纹变了 | 停止连接，向管理员核实是否重装或换了机器 |
| 需要 sudo 密码 | 填服务器账户的管理员密码，不是 QQ 或模型密码；无权限就找管理员 |
| 安装没有回执或连接断了 | 重连后查看原任务；只有确认执行器已停止时再继续，不重复创建新实例 |
| 模型测试失败 | 核对地址、模型 ID、Key、余额及服务器网络；不要把密钥贴在报错截图里 |
| 某组件暂不可用 | 打开组件页查看缺少的依赖或配置；勾选开关不等于运行检查通过 |
| 迁移后显示“接管迁移后的 QQ” | 先停止原服务器的机器人和 QQ，勾选确认后点“启动此处 QQ”；检查账号，再另行启用机器人 |

需要反馈时提供 App 版本、失败阶段、任务编号和已遮住隐私的错误文字。不要发 SSH 密码、API Key、QQ 二维码或数据库备份。

## 停止、备份和删除有什么区别

- **停止机器人**：暂时不回复，数据仍在，可以再启用。
- **备份导出**：将加密的 `.gaojibak` 下载到电脑；记住你设置的备份密码，丢失后无法解密。
- **卸载服务，保留数据**：停止本实例并移除启动项，原数据保留；可通过“重新启用原实例”恢复。
- **彻底删除实例**：先卸载，再核对清单并输入“删除”。该实例的数据库、QQ 会话、文件、服务器内备份、容器及专用卷会被永久删除。
- **移除此连接**：只删电脑里的连接记录，不停止或卸载服务器。

“功能组件 → 存储容量”可以调整数据额度和磁盘预留，“存储管理”查看占用。空间不足会暂停新的大文件操作，不会自动删除数据库或未发送文件；已有文件仍可尝试发送、导出。它不是硬盘硬配额，正在运行的程序仍可能继续占用空间。

“卸载服务、保留数据”和“彻底删除实例”目前指服务器实例的维护向导，不是本机 Docker 一键卸载。直接在电脑使用时，关闭 App 不会删除 Docker 数据，也不保证后台停止；暂时不用可以先停止机器人。不要用 Docker 重置或全局清理代替卸载。

删除实例不会清理共享镜像、Docker、Nix 或其他人的服务。预览版请优先在没有重要数据的测试环境使用；完整实现和验收范围见 [详细说明](README.md)。
