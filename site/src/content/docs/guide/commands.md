除自然语言对话外，gaoji 提供一组由宿主直接处理的斜杠命令（不消耗聊天生成轮次，结果以宿主真实状态为准）。

:::note[命令前缀说明]
所有命令均支持 `/` 或 `!` 开头（如 `/help` 与 `!help` 等价）。在官方 QQ 群聊中，建议以 `@gaoji /命令` 的形式发送，确保平台将消息投递给机器人。
:::

## 常用查询与个人任务

| 命令（含可用别名） | 作用 | 谁能用 |
| :--- | :--- | :--- |
| `/help`（`/帮助`） | 查看当前会话已启用的可用命令列表与简要说明 | 所有人 |
| `/status` | 查看本会话当前状态（是否已停止）、近 24 小时 / 7 天已记录的模型用量与估算费用、今日预算状态，以及你本人的运行中任务 | 所有人 |
| `/usage`（`/用量`、`/token用量`） | 查看你本人在当前入口已完成回合的累计次数与输入 / 输出 Token 总数 | 所有人（仅查本人） |
| `/task [任务ID]`（`/tasks`、`/任务`、`/ps`） | 查看你本人在当前入口正在运行的任务及已运行秒数；也支持 `/task cancel [任务ID]` | 所有人（仅查本人） |
| `/cancel [任务ID]`（`/停止`、`/取消`、`/取消任务`） | 请求取消你本人在当前入口正在运行的任务 | 所有人（仅取消本人任务） |

## 模型、思考强度与上下文

| 命令（含可用别名） | 作用 | 谁能用 |
| :--- | :--- | :--- |
| `/model`（`/模型`、`/切换模型`） | 查看当前生效的模型及可选列表；按宿主策略可用 `/model <名称>`、`/model 默认` 切换或重置，或用 `/model 群默认 <名称>` 设置群默认模型 | 按宿主策略（默认可查看；全局锁定时仅宿主 owner 可改） |
| `/effort [档位 \| 默认]`（`/强度`、`/推理强度`、`/思考强度`、`/reasoning`） | 查看或设置模型的推理思考强度。支持档位：`关闭`（`none`）、`最低`（`minimal`）、`低`（`low`）、`中`（`medium`）、`高`（`high`）、`超高`（`xhigh`）、`最高`（`max`），发 `默认`（`default`）恢复默认 | 按宿主策略查看或修改 |
| `/memory`（`/记忆`） | 查看当前会话保存的长期记忆笔记 | 所有人 |
| `/clear`（`/清空`、`/清空上下文`） | 将当前会话的近期上下文起点推进到最新消息（开启新话题）；之前的历史原文仍保留在账本中，需要时 AI 可用 `history` 查阅 | 所有人 |

## 会话管理与群控制

| 命令 | 作用 | 谁能用 |
| :--- | :--- | :--- |
| `/config` | 查看本会话全部配置项、当前值、默认值与取值范围；用 `/config <名称>` 查看单项 | 所有人可查看 |
| `/config <名称> <值 \| default>` | 修改本会话指定配置项，或传 `default` 恢复默认值（详见下表） | 群主、群管理员或宿主 owner（私聊仅本人） |
| `/stop` | 暂停本会话：继续记录消息，但取消未完成回复与本会话后台任务，不再回复普通消息（斜杠命令仍可用），跨重启保留 | 群主、群管理员或宿主 owner（私聊仅本人） |
| `/start` | 恢复已暂停的本会话；停止期间收到的普通消息与错过的定时执行不会补发 | 群主、群管理员或宿主 owner（私聊仅本人） |
| `/kill` | 请求取消本会话全部排队及运行中的后台任务与后台命令，不改变当前 `/stop` 暂停状态 | 群主、群管理员或宿主 owner（私聊仅本人） |

### `/config` 可配置项一览

任何成员都可以发 `/config` 查看当前群或私聊的配置；群主、群管理员（私聊为本人）可以按名称修改：

| 配置名称 | 默认值 | 取值范围与作用 |
| :--- | :--- | :--- |
| `proactive_enabled` | `on` | `on` / `off`。控制群聊是否允许偶尔主动接话（仍需宿主开启分类器） |
| `agent_timeout_hours` | `6` | `1`–`6`（整数，单位小时）。新发起后台任务的最长运行时限，不改变已运行任务的截止时间 |
| `image_captions` | `off` | `on` / `off`。是否为新入站图片生成文字说明以供历史检索（需宿主配置视觉服务） |
| `image_daily_limit` | `200` | `0`–`10000`。北京时间每天图片说明处理上限，设为 `0` 禁用 |
| `daily_budget_usd` | `off` | 美元金额（最多 6 位小数）、`0` 或 `off`。达到当日已知费用门槛后停止主动接话与程序唤醒（北京时间零点恢复；主动 `@` 或私聊提问仍正常回复，非供应商硬上限） |
| `program_say_limit` | `60` | `0`–`10000`。本会话常驻程序每整点小时发言与发文件共用额度，`0` 为禁用 |
| `program_wake_limit` | `6` | `0`–`10000`。本会话常驻程序每整点小时唤醒模型额度，`0` 为禁用，超额自动合并到下一小时 |

## 沙盒浏览器与进阶状态

| 命令（含可用别名） | 作用 | 谁能用 |
| :--- | :--- | :--- |
| `/logins` | 列出本会话沙盒浏览器当前存有 Cookie 的网站域名（仅反映本地存有站点数据，不代表登录仍有效；沙盒离线时不会擅自开机） | 所有人 |
| `/logout <域名>` | 清理本会话沙盒浏览器在指定域名及其子域的本地状态（不接受完整 URL 或路径；不会撤销你在其他设备上的登录） | 私聊为本人；群公共浏览器需群主、群管理员或宿主 owner |
| `/units`（`/程序`） | 查看本会话沙盒内常驻程序的运行状态与最近投递记录 | 所有人 |
| `/bind`（`/绑定`） | 官方平台会话与身份绑定控制入口（运维与管理用途） | 宿主 owner / 按授权使用 |
