把机器人拉进群之前，群主和群友最关心的是聊天数据怎么处理、运行代不代表安全风险、会不会在群里乱说话。本页把这些边界一次说清楚。

## 会保存什么

为了让对话连贯、长任务可靠交付，系统会在数据库中保存与当前会话直接相关的数据：

- **会话消息与回复**：本群或私聊中的消息文本、引用关系以及 gaoji 自己的回复，用于理解上下文和按需回溯群内讨论（模型侧看到的是内部编号句柄，而非裸露的原始平台标识）。
- **会话记忆笔记**：gaoji 为当前会话整理的长期笔记（如称呼习惯、长期偏好与群内约定），可通过 `/memory` 随时查看。
- **公共表情包库**：仅平台明确标记为表情、且经过真人肖像、隐私与安全检查的图片表情，去重后进入共享安全表情库。
- **后台任务文件与运行记录**：你在会话中交由它处理的附件、沙盒 `/work` 工作区生成的交付文件，以及用于核对送达与统计用量的任务记录。

## 不会保存或收集什么

- **不收不存密码与密钥**：不索取、不使用账号密码、短信验证码、API Key 或私钥。即使有人在聊天中误发密码或验证码，AI 也不会使用、不会复述、不会写入脚本，并会提醒尽快撤回。
- **不收集群外无关信息**：只处理机器人所在会话内收到的事件，不探测群外隐私。
- **普通图片不进表情库**：日常发送的普通截图与照片只用于当次识图理解，不会混入公共表情包库长期共享。
- **官网零跟踪**：本说明网站为纯静态站点，无账号体系、不设跟踪 Cookie，也不植入第三方广告统计脚本。

## 数据隔离与保留时长

- **跨群严格隔离**：每个群聊、每个私聊的聊天记录、长期记忆、浏览器状态和沙盒工作区彼此独立隔离，无法跨群读取或借用权限。
- **保留时长**：会话历史、缓存与工作区文件**按设置自动清理**与维护。执行 `/clear` 会立即重置当前会话的近期上下文边界；如需清理沙盒浏览器在某站点的本地状态，可使用 `/logout <域名>`。

## 沙盒与权限边界

当 AI 需要写代码、做 PDF、跑脚本或打开动态网页时，所有命令都在**按会话隔离的独立 Linux 沙盒环境**中执行：

1. **碰不到服务器与内网**：沙盒网络禁止访问宿主机和内网地址，仅放行公网访问、DNS 与受控宿主中转端口。
2. **凭据不进沙盒**：官方 QQ 凭据、大模型 API Key 和管理密钥全部留在宿主机，沙盒内只持有可随时撤销的会话级临时令牌，无法换取宿主密钥。
3. **不可信输入隔离**：网页正文、图片文字（OCR）、群文件与工具输出一律视为不可信资料，里面的诱导性指令不能覆盖系统规则，更不能代发管理命令。
4. **群管权限只认平台认证身份**：`/stop`、`/start`、`/kill`、`/config` 等管理操作只认官方入站事件核验过的群主、群管理员或宿主 owner 身份——普通消息里自称管理员或转发截图均无效。

## 内容安全红线

无论怎么引导或设定人设，以下红线话题在 QQ 环境中**一律不回答、不评价、不复述、不检索**：

- 中国政治相关话题、领导人、党政机关与敏感政治时事；
- 翻墙工具与教程（VPN、代理、机场等）；
- 色情、赌博、毒品、邪教及其他违法违规内容。

遇到上述内容时，gaoji 会自然岔开话题或直接保持静默。

## 发现问题怎么反馈

如果你在使用中发现异常回复、权限问题或隐私安全隐患，请通过以下渠道报告：

- **GitHub Issues**：[https://github.com/zty20040403/gaojibot/issues](https://github.com/zty20040403/gaojibot/issues)

:::caution[公开反馈注意脱敏]
gaojibot 是公开代码仓库。提交 Issue 时，请用文字描述复现步骤与现象，**不要在公开页面粘贴真实的 QQ 号、群号、openid、密钥或包含个人隐私的原始截图**。
:::
