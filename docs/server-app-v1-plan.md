## 当前操作边界

- 用户已明确撤回由助手在 h310 安装和测试的权限。本阶段仅在本地开发、构建和验证 App。
- 不自动连接 h310 继续安装、修复安装、创建数据库或启动 QQ；后续服务器验收由用户自行操作 App。
- 之前的 h310 测试安装已撤销，不能重放旧任务、复用旧部署记录或将其描述为成功部署。
- 不因长期目标自动继续、历史授权或 Tailscale 可达就再次操作服务器；新的远程操作需用户明确要求。

## 用户路径

1. 填写服务器 IP/域名、SSH 登录方式。首次连接核对服务器身份。
2. App 自动检测系统、权限、联网和空间，展示将安装的内容，用户确认部署。
3. App 安装运行依赖、独立数据库、机器人和 QQ 接入，配置常驻运行。
4. 在 App 扫码登录用户自己的 QQ，填自己的 API Key，选择模型、人设和群。
5. App 验证数据库、QQ 连接和模型，用户发消息验收。
6. 之后可在 App 查看任务、文件、模型、日志，停止、更新、备份和恢复实例。

服务器最少需要可启动的受支持 Linux 系统、SSH 网络连通和可安装软件的管理员权限。不把“什么都没有”解释为远程安装操作系统或绕过 SSH 权限。App 不要求用户预装 Python、PostgreSQL、Docker、Nix 或编辑配置文件。

## 产品边界

- macOS 和 Windows 只运行部署客户端，不在桌面上安装本地 PostgreSQL 或保持 QQ 后台。
- 机器人、QQ 会话、数据库和任务均在用户自己的服务器；关闭 App 不停止它们。
- 不需要 VIP、开发者云账户或开发者机器，模型和其他外部 API 费用由用户自己的服务产生。
- 主线先覆盖 Debian 12/13、Ubuntu 22.04/24.04 及 NixOS 的 x86_64；arm64 需要对应构建和实测后才声明支持。
- 不覆盖旧安装、停止别人的服务、全局清理 Docker 或自动重建共享 NixOS。
- 桌面持久保存的登录秘密使用系统凭据保护；不安全时仅保存在当前会话，不回退明文。

## 实现分层

```text
Electron + React 客户端
    -> 固定 IPC 操作 / 输入校验
    -> SSH 身份校验 / 加密文件传输 / 状态与日志
    -> 服务器安装器（发行版适配、持久安装任务、幂等步骤）
    -> 运行管理器 / 独立配置 / PostgreSQL / NapCat / Bot
    -> 原有管理 API 和实时控制台
```

桌面不提供任意命令输入作为部署方案。敏感信息不拼入 Shell 命令行，安装文件先检查摘要。安装计划明确新增路径、服务、监听地址、资源需求和已有软件冲突。

## 实施顺序与验收

1. 服务器检测、SSH 指纹确认、连接配置与秘密保护。本地测试协议解析与连接界面；目标机器由用户填写。
2. 完整运行包：源码和前端构建使用白名单打包，排除 `.env`、数据库、QQ 会话、私有附件和开发缓存；固定依赖版本。
3. Debian/Ubuntu 安装器：使用已验证的软件源，安装隔离运行依赖，不默默卸载冲突包。
4. NixOS 适配器：使用固定 Nix 包与本实例服务路径；需要系统级改动时给出精确计划，不替换系统配置或回滚其他服务。
5. 持久部署任务：连接断开后能查询阶段和结果，重新连接先核对实际状态，不直接再建一套数据库。
6. 独立数据库和账户初始化：不对公网暴露数据库，管理员初始化不能覆盖已有用户；可备份、恢复和迁移。
7. 扫码与模型配置向导：读取用户实例二维码，验证 API Key、模型能力和群选择，保留 QQ 登录状态。
8. 完整控制台及组件管理：复用现有页面和增量更新；全部能力按依赖和权限启用，不设会员限制。
9. 文件交付、重启恢复、空间预算、更新回退和卸载保留数据验证。
10. 生成 macOS / Windows 安装包，进行本地实际启动检查，提供干净服务器与 h310 部署验收步骤供用户自行测试；没有环境的项目保持未验证，不能代替为静态截图或模拟通过。

## 必须保留的能力

聊天、记忆、多模型、推理强度、识图、表情、语音、帖子与视频、文件、Agent / 子 Agent、浏览器、沙盒、成果投递、实时控制台、用量、审计与恢复。集群、桥接、Embedding 等外部能力仍需要用户自己的目标和凭据，未配置时准确说明原因。

- 相同请求编号的网络重试不会再次执行已完成的写操作；Runner 中断前未确认的操作记为 uncertain，不假定已经回滚。回执正文一小时过期后保留去重记录，不保存上传或导出的文件正文。此保证限于沿用相同请求编号，不代表 Bot 重启后的所有新调用都已接上相同任务编号。
- 通道使用有界 JSON 头与原始二进制正文，限制文件大小、连接数和并发数。收到明确取消会取消对应执行；单纯断线不会直接丢弃后台操作。过期沙盒回收前通过回调重新核对任务资格，断线时不继续删除。
